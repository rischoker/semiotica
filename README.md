# Σ Semiótica en Español · OVA

Objeto Virtual de Aprendizaje para una clase de español sobre semiótica (Saussure, Peirce y Barthes).
El scroll hace avanzar una cámara por un túnel 3D (Three.js + GSAP) y cada pantalla espera más adentro.

## Pantallas
1. El gancho (Eco)
2. Saussure: significante y significado, arbitrariedad
3. Comparador de memes (mismo significado, dos significantes)
4. Tarjeta 3D de ejemplos
5. Peirce: triángulo del signo
6. Ícono, índice y símbolo
7. Laboratorio de signos (mini-juego)
8. Barthes: denotación y connotación
9. Anuncio interactivo con hotspots
10. Reto final en Wordwall

## Personalizar
- **Wordwall:** cambia la constante `WORDWALL_URL` al inicio del `<script>` final de `index.html`.
- **Retratos:** añade `assets/saussure.jpg`, `assets/peirce.jpg`, `assets/barthes.jpg` y `assets/eco.jpg`.
  Mientras no existan, se muestran las iniciales en neón.

Navegación: rueda del mouse, flechas ↑ ↓, barra espaciadora o los botones ▲ ▼.
